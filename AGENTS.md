# Project rules

- Do not run a build unless the user asks or there is evidence of an error requiring it.
- Mandatory: no artwork from AI image-generation models anywhere in this project, including characters, sprites, environments, icons, portraits, loading screens, or menu backgrounds. Original pixel art drawn through editable code and deliberately authored animation frames is allowed.
- Use credited artist-made assets and original pixel art with editable pixel patterns and deliberately authored animation frames. Custom sprites, armor, and structures drawn through code are allowed. Do not invoke image generation for this project, and do not claim code-authored art was drawn by a human artist.
- Assemble the world from real layered tiles and sprites. Preserve crisp pixels, correct occlusion, visible height, and structure depth.
- Optimize for the available Intel UHD integrated GPU; measure runtime performance and avoid unnecessary per-frame work.
- The playable world is now small, fixed, and deliberately authored. Do not reintroduce procedural terrain, random layouts, or expansion to a large world without the user's request.
- Aim for an original aesthetic informed by classic Pokémon exploration and Deltarune's expressive pixel characters and readable contrast. Preserve the game's own characters, story, and identity.
- Unique and endepth magic and combat systems inspired from manhwas and a fuclly fledged economy is a must every action of the user should have consequesnses
